# Bundled sample

`souls_of_black_folk.txt` is the Forethought and the first three chapters of
W. E. B. Du Bois, *The Souls of Black Folk* (1903), from Project Gutenberg
ebook #408. The text is in the public domain; the Project Gutenberg header,
licence, and trademark text have been removed as that licence requires when
the file is redistributed without them. Light clean-up: lines reflowed into
paragraphs, verse kept indented, `[Illustration]` markers dropped.

`sample.pdf` is typeset from that text by `scripts/make_sample.py` with a
title page, a provenance page, roman folios on the front matter, a PDF
outline, alternating running heads, printed folios, and hyphenation at the
margin, so that it looks to the extractor like a real book. It is the one
PDF deliberately committed to this repository, and it is what `dsearch demo`
indexes. Regenerating it produces identical bytes.
